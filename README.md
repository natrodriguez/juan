# Juan — juan.cr

A responsive Spanish / English portfolio, built with HTML, CSS and JavaScript. No build tools or installation required.

## GitHub Pages

In this repository, open **Settings → Pages**. Choose **Deploy from a branch**, select **main** and **/ (root)**, then Save.

The default address is https://natrodriguez.github.io/juan/.

When ready to connect juan.cr, enter it under Pages → Custom domain and configure only that domain's DNS according to GitHub's current Pages instructions. Sámara Limpia's records do not need changes. A CNAME file is intentionally omitted until the domain is connected.

## Editing

- `index.html`: content. Spanish and English text is stored in `data-es` / `data-en` attributes.
- `style.css`: layout and earthy palette.
- `script.js`: language switching, with a saved preference. Spanish is the default.
- `assets/`: optimized portrait and book cover.

The YouTube Comments link opens the video on YouTube. The Costa Rica purchase link opens WhatsApp; the US link opens Native America's store.
